# \## 📱 Что это?

# 

# \*\*Memogram\*\* — приложение для обмена мемами с элементами социальной сети:

# 

# \- 📤 Публикуй мемы в ленту и сообщества

# \- 💬 Общайся в личных чатах (отправляй текст и картинки)

# \- ❤️ Ставь реакции, сохраняй в избранное

# \- 📝 Комментируй посты

# \- 👥 Создавай сообщества, подписывайся на пользователей

# \- 🎨 Настраивай цветовую тему под себя

# 

# \---

# 

# \## 🛠 Технологии

# 

# | Слой | Стек |

# |------|------|

# | \*\*Frontend\*\* | Flutter 3.x (Dart) |

# | \*\*Backend\*\* | PHP 8.x |

# | \*\*Database\*\* | MySQL 8.x |

# | \*\*Storage\*\* | Файловая система сервера (изображения) |

# | \*\*Auth\*\* | SharedPreferences (клиент) + PHP-сессии |

# \## 📂 Структура проекта

# ```

# memogram/

# ├── lib/ # Flutter-приложение

# │ ├── main.dart # Точка входа

# │ ├── screens/ # Все страницы

# │ │ ├── feed\_page.dart # Лента постов

# │ │ ├── chat\_page.dart # Личные сообщения

# │ │ ├── chats\_page.dart # Список чатов

# │ │ ├── communities\_page.dart # Сообщества

# │ │ ├── profile\_page.dart # Профиль

# │ │ ├── settings\_page.dart # Настройки

# │ │ ├── login\_page.dart # Вход/регистрация

# │ │ ├── edit\_profile\_page.dart

# │ │ ├── about\_page.dart

# │ │ ├── admin\_page.dart

# │ │ └── linking.dart # Парсер @упоминаний и ##сообществ

# │ └── widgets/ # Переиспользуемые виджеты

# │ ├── avatar\_widget.dart # Аватар с дефолтной картинкой

# │ └── image\_viewer.dart # Полноэкранный просмотр изображений

# ├── assets/ # Ресурсы

# │ └── default.png # Дефолтная аватарка

# ├── hosting/ # Бэкенд (PHP)

# │ ├── init.sql # Схема базы данных

# │ ├── \*.php # API-эндпоинты

# │ ├── about.md # Markdown для страницы "О приложении"

# │ ├── .htaccess # CORS и MIME-типы

# │ └── index.html # Лендинг сайта

# ├── pubspec.yaml

# ├── .gitignore

# └── README.md

# ```

# Инструкция по старту проекта:

# \- Создать flutter-проект в VS Code (или другой удобной среде)

# \- Обновить pubspec.yaml

# \- копировать содержимое папки lib с свой проект в эту же папку

# \- обновить (если нет - создать) следующие файлы:

# &#x20; - C:\\dev\\f\_projects\\memogram\\android\\app\\src\\main\\AndroidManifest.xml

# &#x20; - C:\\dev\\f\_projects\\memogram\\android\\app\\src\\main\\res\\xml\\network\_security\_config.xml

# \- разместить серверную часть проекта на своём хостинге (непосредственно в корне: https://your\_domain.com/\[файлы папки hosting])

# \- ввести настройки своей бд в файл config.php

# \- импортировать init.sql в свою бд

# \- собрать проект: во flutter-терминале ввести flutter build apk --release --split-per-abi
